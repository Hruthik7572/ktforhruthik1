# AWS Lambda deployment

This ASP.NET Core 10 API is configured for an API Gateway HTTP API (payload v2) backed by Lambda. `Amazon.Lambda.AspNetCoreServer` adapts Lambda events to the existing ASP.NET Core `Startup` pipeline.

## AWS prerequisites

- Use a Linux Jenkins agent with Bash, the AWS CLI, the .NET 10 SDK, and AWS credentials available through an attached IAM role or Jenkins-managed AWS credentials.
- Create an AWS Secrets Manager secret whose `SecretString` is the SQL Server connection string. The Lambda role generated by the SAM template receives `secretsmanager:GetSecretValue` for that secret ARN. If the secret uses a customer-managed KMS key, grant the Lambda role `kms:Decrypt` for that key as well.
- Ensure the SQL Server endpoint is reachable from Lambda. For a private database, configure the Lambda VPC/subnets/security groups and the required network route.
- Create or select an S3 bucket in the target region for deployment artifacts. The Jenkins agent's AWS identity needs permission to upload deployment packages and manage the CloudFormation/Lambda/API Gateway resources.

For local development, set `ConnectionStrings__StudentDb` in the environment. Lambda uses the `StudentDbSecretArn` environment variable and retrieves/caches the secret for each warm application instance. The raw connection string is not committed or passed as a deployment command parameter.

## Jenkins deployment

The existing pipeline restores the pinned AWS Lambda CLI tool, builds, runs unit tests, and publishes artifacts. Deployment is opt-in: run the Jenkins job with `DEPLOY_TO_AWS` enabled and supply `AWS_REGION`, `AWS_STACK_NAME`, `AWS_DEPLOYMENT_BUCKET`, and `AWS_DB_SECRET_ARN`. The agent must already have AWS credentials with the permissions above. Jenkins invokes `scripts/deploy-lambda.sh`, which validates its environment, checks the active AWS identity, restores the pinned Lambda tool, and uses `serverless.template` to create or update the Lambda function and API Gateway HTTP API.

To deploy from a shell on an authorized Jenkins agent, set the four variables above and run:

```sh
bash scripts/deploy-lambda.sh
```

The Lambda function and API Gateway resources are created or changed by this deploy command.
